Privacy Policy for Minimalista

Last updated: June 12, 2026
Minimalista is a browser extension that replaces your new tab page with a minimal, customizable interface. This policy explains how the extension handles data.
Data We Collect

Minimalista does not collect, transmit, or store any personal information. No analytics, tracking scripts, or telemetry of any kind are included.
Local Storage

Your preferences (selected wallpaper, theme, search engine, layout settings) are saved locally on your device using the browser's built-in storage API (chrome.storage.local). This data never leaves your browser and is not accessible to any server or third party.
Network Requests

The extension fetches wallpaper images from a public GitHub repository (raw.githubusercontent.com/jikokoutei/Gostlist). These are one-way image downloads. No user data, identifiers, or metadata are sent to GitHub or any other server as part of this process. GitHub's own privacy policy governs their handling of standard request logs.
Permissions

storage: Used to save your preferences locally.
tabs: Used to open the extension page when the toolbar icon is clicked.

Third-Party Services

No third-party analytics, advertising, or data-sharing services are used.
Changes

If this policy changes, the updated version will be published with the extension update.
